Exemplo 32 - Exercício de Aplicação de Classes

Instruções

Neste exercício você deverá praticar a aplicação de classes CSS nos elementos HTML.

Utilize as classes disponíveis no arquivo estilos.css para modificar a aparência dos textos abaixo.

Você deverá experimentar as classes destaque, cursiva, italico, sublinhado, azul, negrito e google.

Lembre-se de que é possível utilizar mais de uma classe no mesmo elemento.

Parte 1 - Aplicando uma classe

O HTML é uma linguagem utilizada para criar a estrutura das páginas da internet.

O CSS é utilizado para definir a aparência dos elementos, como cores, tamanhos e tipos de fontes.

Aplique uma classe diferente em cada parágrafo acima.

Parte 2 - Utilizando mais de uma classe

As classes podem ser combinadas para criar diferentes efeitos visuais.

Por exemplo, uma palavra pode ficar azul e em negrito.

Outra palavra pode ficar itálica e sublinhada.

Agora escolha outras palavras deste texto e aplique duas ou mais classes ao mesmo tempo.

Parte 3 - Trabalhando com fontes

A escolha da fonte pode alterar completamente a aparência de um texto.

A classe destaque utiliza uma fonte diferente e aumenta o tamanho do texto.

A classe cursiva apresenta o texto com uma aparência semelhante à escrita à mão.

A classe google possui uma fonte que pode ser personalizada pelo aluno no arquivo estilos.css.

Parte 4 - Desafio

Escolha uma frase deste exercício e aplique pelo menos três classes diferentes ao mesmo elemento.

Depois, crie uma nova classe no arquivo estilos.css e utilize essa nova classe em uma parte deste texto.

Sua nova classe deve modificar pelo menos uma característica visual, como cor, tamanho, estilo ou família da fonte.

Objetivo do exercício

Ao terminar este exercício, você deverá saber como criar, aplicar e combinar classes CSS nos elementos de uma página HTML.

Pratique, teste diferentes combinações e observe como cada classe altera a aparência do texto.
